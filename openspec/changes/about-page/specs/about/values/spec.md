## ADDED Requirements

### Requirement: Icon rows

The section SHALL show a heading and three to five values, each an icon, a title and one line, in two columns from 768px up and one column on phones. There SHALL be no action button.

#### Scenario: Values render

- **WHEN** the values render at 1440px
- **THEN** they sit in two columns, each with an icon, title and line

### Requirement: Owner-approved

Every value SHALL be a placeholder until the owner approves it.

#### Scenario: Report

- **WHEN** the report runs
- **THEN** each value is listed under About
