## Purpose

How to ask Akik about a project like this one.

Source: Obvious closing block (captured, frame 11), as built for Home's Visit us.

## ADDED Requirements

### Requirement: WhatsApp to Engineering

The page SHALL end with a closing block whose heading invites the visitor to build or buy something similar, and a `primary` WhatsApp pill to the Engineering number prefilled with "Hello Akik, I saw {project name} and I'd like to ask about".

#### Scenario: Asking about a project

- **WHEN** a visitor taps the pill on a project page
- **THEN** WhatsApp opens to the Engineering number with the project's name in the message
